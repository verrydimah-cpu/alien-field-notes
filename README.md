An alien tourist's one-line review of Earth, written to `entry.txt`. The program clears the output directory entry by entry (never removing the directory itself), then writes a single tight review line — a two-star verdict on Earth's hospitality from a visitor who spent two days signalling from a crop circle and was photographed, argued about online, and never once offered snacks. Node 22 and its standard library alone: no dependencies, nothing to install.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the review to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when the variable is set). Running it again produces byte-identical output.
